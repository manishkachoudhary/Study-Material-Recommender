# 📚 Study Material Recommender System

A Hybrid Machine Learning-based Study Material Recommendation System built using Streamlit.

This system recommends personalized study materials using:

- Decision Tree Classifier
- Collaborative Filtering
- Content-Based Filtering
- Real-Time Learning Analytics Dashboard

---

## 🚀 Features

- 🎯 Hybrid ML Recommendation Engine
- 📊 Real-Time Analytics Dashboard
- 📈 Learning Progress Tracking
- 📂 Class-wise and Subject-wise Filtering
- 📄 PDF Viewer & Video Support
- 🧠 Model Accuracy Gauge Visualization
- 🔥 Category Popularity Heatmap

---

## 🛠 Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 🧠 ML Techniques Used

1. Decision Tree Classification
2. Collaborative Filtering
3. Content-Based Filtering
4. Hybrid Recommendation Strategy

## ▶️ How to Run

1. Install dependencies:


pip install -r requirements.txt


2. Run the application:


streamlit run app.py
